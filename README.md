# Fatebound

Dice arena game plus an Android app bundle for Google Play.

- Play Store name: **Fatebound**
- Package id: `com.fatebound.game`

## Get an `.aab` for Play Console

1. Open https://github.com/midblade4295/Dice-skirmish/actions
2. Click **Build Play Store AAB**
3. Click **Run workflow**
4. Download **fatebound-play-aab** and unzip `app-release.aab`
5. In Play Console, create the app as **Fatebound** with package `com.fatebound.game`
6. Upload the `.aab`

Save **fatebound-upload-keystore** from the same run for future updates.
