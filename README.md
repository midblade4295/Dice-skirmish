# Fatebound

Fatebound arena game plus an Android app bundle for Google Play.

- Play Store name: **Fatebound**
- Package id: `com.fatebound.game`
- Game file: `fatebound.html`

## Get an `.aab` for Play Console

1. Open the repo Actions tab
2. Click **Build Play Store AAB** → **Run workflow**
3. Download **fatebound-play-aab** and unzip `app-release.aab`
4. In Play Console, create the app as **Fatebound** / `com.fatebound.game`
5. Upload the `.aab`

Save **fatebound-upload-keystore** from the same run.
